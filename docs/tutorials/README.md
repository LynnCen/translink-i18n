# 深度教学

> **理解「为什么」比知道「怎么做」更重要。**

本教程从**工程问题**出发，带你理解每个设计决策背后的原理。学完后，你不只会用这个工具，还能设计类似的系统。

## 教学特点

### 问题驱动

每章从「我们要解决什么问题」开始，而非「如何写代码」。

### 决策分析

展示设计时的权衡过程：为什么选 A 而非 B？

### 原理优先

理解背后的设计模式和工程原理，代码只是验证。

### 专业术语

使用准确的技术术语，对接行业知识体系。

## 前置知识

**必需**：
- TypeScript 基础语法
- npm/pnpm 包管理
- 至少一个前端框架（Vue/React）

**推荐**：
- 了解 AST 概念
- 了解 Vite 基本使用
- 设计模式基础

---

## 学完能获得什么

1. **系统思维**：理解复杂工程问题的分析和拆解方法
2. **架构能力**：掌握关注点分离、开放封闭等设计原则的应用
3. **实现能力**：学习 AST 解析、插件系统、Provider 抽象等实用技术
4. **优化意识**：理解构建优化、Tree-shaking 的原理和实践
