## 🎯 快速开始

```bash
# 1. 安装
npm install @translink/i18n-cli @translink/i18n-runtime

# 2. 初始化
npx translink init

# 3. 提取文本
npx translink extract

# 4. 翻译（可选）
npx translink translate --to en-US
```
